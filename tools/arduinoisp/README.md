# ArduinoISP

The official ArduinoISP sketch (BSD licence, Randall Bohn), unmodified, from
[arduino/arduino-examples](https://github.com/arduino/arduino-examples). It turns
an Arduino Uno into the programmer for the ATtiny85.

```
pio run -t upload
```

Wiring to the board is in the [firmware README](../../Firmware/README.md).
